윈도우 노트북용 NetRF PC

패드 없이 노트북 와이파이로 같은 측정(신호·로밍·속도·품질 모니터)을 합니다. 설치 없이 zip 을 풀고 NetRF-PC.exe 를 켜면 화면이 브라우저로 열립니다.

NetRF PC 받기0.24 · 약 6 MB · 윈도우 x64

"Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행. 아직 코드 서명 전이라 스마트 앱 컨트롤이 켜진 PC 에서는 실행이 막힙니다. 기록은 그 PC 안에만, 측정 끝나고 8시간 뒤 지웁니다.

준비물

  • ①안드로이드 패드·폰 — NetRF 를 깔아 들고 다니며 잽니다.
  • ②윈도우 PC·노트북 한 대(측정 서버) — 사업장 유선(랜선)에 꽂아 두고 netrf-server.exe 를 켭니다.패드 ↔ AP ↔ 유선 ↔ PC 사이 속도 = 무선 구간만의 속도를 재는 상대입니다. 없으면 인터넷 속도만 재서, 느릴 때 와이파이 탓인지 회선 탓인지 가르기 어렵습니다.
  1. 크롬으로 열어 받기(Google 앱 안에서는 멈춤)
  2. 받은 파일 열기 → 설치
  3. 처음 실행 때 위치 권한 허용(BSSID 읽기용)
  4. 로밍 기록은 이 기기 안에만, 측정 끝나고 8시간 뒤 저절로 지움 — 서버로 보내거나 꺼내는 기능 없음
  5. 설치가 막히면(사업장 MDM 정책) 개인 폰으로도 됩니다

측정 서버 켜기(윈도우 PC)

  1. PC·노트북을 사업장 유선(벽 랜 포트·스위치)에 꽂는다 — 와이파이로만 붙으면 무선을 두 번 타서 값이 섞인다
  2. 아래 netrf-server.exe 를 받아 마우스 오른쪽 → 관리자 권한으로 실행(설치 없음)
  3. 창에 유선 http://<IP>:8098 이 보이면 준비 끝 — 켜 둔 채로
  4. 패드 NetRF → 속도 탭 → 속도 측정 시작 — 같은 망이면 서버를 저절로 찾습니다
  5. 무선 컨트롤러(WLC)를 쓰는 망(회사망 대부분)은 단말의 방송을 버려 저절로 못 찾습니다 → NetRF ⚙ → 무선 구간 서버에 창에 보이는 http://<IP>:8098 을 넣고 측정(한 번 넣으면 기억 — 늘 같은 PC 를 쓰면 편함)
  6. 끝나면 창 닫기(30분 동안 측정이 없으면 저절로 꺼짐)
윈도우용 netrf-server.exe약 7 MB · 받은 데이터는 저장하지 않음

관리자 권한으로 켜야 방화벽을 저절로 열고 닫을 때 지웁니다(사업장 유선은 보통 "공용 네트워크"라 그냥 켜면 패드가 못 붙기 쉽습니다). "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행. 리눅스: netrf-server-linux

회사 PC 라 exe 를 못 받을 때(파이썬)
  1. PC 에 파이썬 3 이 있으면 speed-server.py 를 받아 그 폴더에서 python speed-server.py(설치 없음) — 창에 뜬 http://<IP>:8098 을 NetRF ⚙ 에
  2. 파이썬 판은 방화벽을 스스로 열지 않습니다. 방화벽이 켜진 PC 면 관리자 명령 프롬프트에서 8098 만 엽니다:
    netsh advfirewall firewall add rule name=NetRF-8098 dir=in action=allow protocol=TCP localport=8098 profile=any
  3. 다 쓰면 닫기: netsh advfirewall firewall delete rule name=NetRF-8098
리눅스 서버에 상시로 띄우기(파이썬·도커)
  1. 파이썬 3 만 있으면: speed-server.py 받아 python3 speed-server.py(설치 없음, 표준 라이브러리만)
  2. 도커: netrf-server-docker.zip 풀고 그 폴더에서 docker compose up -d — 재부팅해도 다시 뜸
  3. 서버는 유선·무선 단말과 다른 VLAN 인 경우가 많아 자동 찾기가 안 됩니다 — NetRF ⚙ → 무선 구간 서버에 http://<서버 IP>:8098, 방화벽은 TCP 8098
패드가 서버를 못 찾을 때
  1. PC 브라우저 http://localhost:8098/__info — 글자가 나오면 서버는 정상
  2. 패드 브라우저 http://<창의 IP>:8098/__info — 열리면 서버·망은 정상, NetRF ⚙ 의 주소(IP·포트)를 다시 확인
  3. 안 열리면 방화벽(관리자 권한으로 다시) 또는 무선 → 유선이 막힌 망(손님 SSID·다른 VLAN·ACL) — PC 를 무선 단말과 같은 VLAN 포트에 꽂거나, 망 담당자에게 무선 대역 → PC TCP 8098 허용을 부탁
  4. 관리자 권한이 없는 회사 PC 는 PC 담당자에게 netrf-server.exe 방화벽 허용(또는 TCP 8098)을 부탁
  5. 한 PC 는 되고 다른 PC 는 안 될 때는 먼저 무선 컨트롤러 ACL(PC IP 별 허용)을 의심 — 된 PC 브라우저에서 http://<안 된 PC IP>:8098/__down?bytes=1000 이 열리면(유선끼리라 WLC 를 안 탐) 그 PC 는 정상이고, 무선 쪽 ACL 에 그 IP 가 없는 것
